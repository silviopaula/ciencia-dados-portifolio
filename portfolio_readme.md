## Competências Principais

### Análise Estatística & Inferência
- **Testes de Hipóteses**: A/B Testing, Mann-Whitney U, t-test, Chi-quadrado etc.
- **Séries Temporais**: AARIMA, SARIMA, SARIMAX, Auto-ARIMA, Exponential Smoothing (Holt-Winters), VAR, VARMA, LSTM, Prophet. TimeGPT, TimeFM, Cronos, Exponential Smoothing, DeepAR
- **Inferência Causal**: Difference-in-Differences (DID Callaway & Sant’Anna (2021)), RDD, Synthetic Control, Propensity Score Matching (PSM), Synthetic Control, CausalImpact, IV, SEM (Structural Equation Modeling), BSTS e outros
- **Econometria Análise Multivariada**: PCA, Clustering, Análise de Componentes OLS, FE, RE, Logit, Probit, Painel Dinâmico, Unconditional Quantile Regression (UQR) e outros 
- **Modelos dinâmicos e espaciais**: SAR, SEM, SDM, SDEM, SLX,Estatística de Moran, Interpolação espacial.



### Machine Learning
- **Classificação**: Logistic Regression, Random Forest, LightGBM, XGBoost, AdaBoost, CatBoost, SVM, Naive Bayes, Decision Trees, KNN, Gradient Boosting, Extra Trees
- **Regressão**: Linear/Ridge/Lasso, Elastic Net, Polynomial Regression, SVR, Ensemble Methods (Stacking, Bagging, Voting)
- **Deep Learning**: LSTM, RNN, Neural Networks (TensorFlow/Keras)
- **AutoML**: PyCaret, AutoKeras, Auto-sklearn, H2O AutoML
- **Clustering**: K-Means, Hierarchical Clustering, DBSCAN, GMM, Mean Shift, Spectral Clustering
- **Feature Engineering**: Scaling, Encoding, Selection, Dimensionality Reduction (PCA, t-SNE, UMAP), Polynomial Features
- **Model Evaluation**: Cross-Validation, Metrics (Accuracy, F1, AUC-ROC, RMSE, MAE, MAPE, AUC-ROC, F1-Score, R²), Hyperparameter Tuning (Grid/Random/Bayesian)


### NLP & Análise de Texto
- **Text Mining**: Tokenização, Stemming, Lemmatization
- **Sentiment Analysis**: Dicionários especializados (Loughran-McDonald)
- **Processamento**: Regex, String manipulation, Text normalization
