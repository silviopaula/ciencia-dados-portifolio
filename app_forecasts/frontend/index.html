App Forecasts

Solução completa para importação multi-formato, engenharia de variáveis temporais, decomposição sazonal e projeções avançadas com PyCaret / Machine Learning, ARIMA / SARIMAX e AutoTS.

Importação Inteligente & 8 Etapas

Suporte a CSV, Excel (.xlsx/.xls), RDS, Stata (.dta), SPSS (.sav) e SQLite com conversão automática para date_ok, geração de dummies (anos, meses, estações, B-ró B-ró, crises), transformações Log/Box-Cox e decomposição sazonal.

Machine Learning (PyCaret & Recipes)

Mais de 100 variantes de modelos (Regressões Lineares, Penalizadas, SVM, Random Forest, ExtraTrees, Gradient Boosting, XGBoost, Redes Neurais), engenharia de features (Lags, Janelas, Polinômios, PCA/ICA/PLS), Gráfico em Cascata de Importância e Elasticidades.

Modelos ARIMA, SARIMAX & AutoTS

Busca automática de ordens ARIMA univariadas e multivariadas (com exógenas), suíte AutoTS (Prophet, ETS, SARIMA, TBATS, BATS, STLM, Bagged Ensemble), dashboards de recomendação por score composto e análise de crescimento Mensal, Trimestral, Semestral e Anual.

Dicas Rápidas

  • Comece importando seus dados em CSV, Excel, RDS, Stata ou SQLite (ou use o botão Carregar Exemplo Rápido no topo).
  • Converta a coluna temporal para date_ok para habilitar a geração de dummies, transformações e decomposição sazonal.
  • Em Projeções ML, compare o Score Composto no Dashboard de Backtest e inspecione o Gráfico em Cascata de Importância e as Elasticidades.
  • Em AutoTS, utilize a aba Análise de Crescimento para obter tabelas Mensais, Trimestrais, Semestrais e Anuais com variações YoY.

Arquitetura Modernizada (Python + Web SPA)

  • Frontend 100% Web Moderno: HTML5, CSS3 e JavaScript ES6 puro com gráficos interativos Plotly.js (zero Python no frontend).
  • Backend Python FastAPI: Processamento vetorial rápido com Pandas, NumPy, SciPy, Statsmodels, Scikit-Learn, XGBoost e arquitetura compatível com PyCaret.
  • Exportação Completa: Planilhas Excel multi-abas (.xlsx), CSV UTF-8 e objetos de modelos treinados (.joblib).
